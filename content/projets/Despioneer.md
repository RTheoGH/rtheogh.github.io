**Despioneer** is a 2D game developed with **Godot Engine**.\
It was created as part of a game jam on the theme "**Pioneer**".

In this dystopian game, humans send probes (pioneers) into space - not to showcase humanity, but to wreak as much havoc as possible on other planets!

Our 4 constraints:
1. You actually learn something!
2. The game can be speedrun (but it's hidden)
3. The villain is the main character
4. One environment = one graphic style
